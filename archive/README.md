# Arsip

Kode dan dokumen dari konsep sebelumnya, **Tebar** (teka-teki tebar harian), yang diganti dengan Adu Layangan pada 14 November 2026. Tidak ikut di-build, diuji, atau di-lint.

- `PRD-tebar.md` — PRD Tebar.
- `tebar-src/` — mesin congklak, pemecah, pembuat papan harian, tampilan papan, dan logika server Tebar (penilaian, streak, peringkat), dengan ujinya. Pola server dan uji di sini dipakai ulang untuk Adu Layangan.
